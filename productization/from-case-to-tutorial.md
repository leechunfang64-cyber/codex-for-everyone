# 从案例到教程

案例是你做过什么，教程是别人如何复现。二者的差别，是内容能不能从“炫耀结果”变成“交付方法”。

## 教程结构

一个可复现教程至少包含：

- 背景：为什么做。
- 成品：最终效果是什么。
- 准备：需要哪些工具和账号。
- 步骤：按顺序执行。
- 验证：怎么知道成功。
- 排障：失败时看哪里。
- 延伸：如何改成自己的版本。

## Codex 教程提示词

```text
请把这个项目复盘成一篇教程。
目标读者是会基础电脑操作但不熟悉编程的人。
要求每一步都能执行，包含命令、预期输出、失败处理和截图占位。
不要写空泛感想。
```

## 价值

教程的价值不是流量本身，而是信任。读者照着做成功一次，就会相信你不只是会讲概念。

信任是后续模板、课程、咨询、社群和产品销售的基础。
