# 从一次开发到长期资产

一次开发如果只留下代码，价值有限。如果留下代码、文档、提示词、排障记录、案例文章和模板，它就开始变成资产。

## 资产化清单

每个项目结束后，至少沉淀：

- README：别人怎么安装和使用。
- Prompt：你如何让 Codex 理解需求。
- Troubleshooting：过程中遇到的坑。
- Demo：可访问或可截图的结果。
- Case：这个项目为什么值得做。
- Template：下一次能不能复用。

## Codex 复盘提示词

```text
请复盘本次项目，把它整理成长期资产：
1. 需求背景
2. 实现路径
3. 关键提示词
4. 验证命令
5. 遇到的问题和解决方式
6. 下次可复用模板
7. 是否具备产品化价值
```

## 复利来自哪里

复利不是来自“做了很多项目”，而是来自每个项目都减少下一次成本。

- 同类项目启动更快。
- 常见错误不用重查。
- 文档能直接发给用户。
- 案例能成为内容素材。
- 模板能成为虚拟产品。

一次开发消耗时间，资产化让时间回来。
