# 开发图片处理工具

## 适用场景

图片处理工具适合解决批量重复劳动：压缩、裁剪、改尺寸、加水印、转格式、生成封面图。不要从“我要做 Photoshop”开始，要从一个高频小动作开始。

## 需求拆解

- 输入：图片文件夹。
- 输出：处理后的图片文件夹。
- 核心动作：压缩、尺寸调整、格式转换、水印。
- 验收：处理前后文件数量一致，尺寸和体积符合预期。

## Codex 提示词

```text
请帮我开发一个批量图片处理工具。
第一版只做命令行：输入文件夹、输出文件夹、目标宽度、输出格式。
请优先使用成熟图片库，不要手写图片算法。
完成后提供示例命令和验证方法。
```

## 实现步骤

1. 选择 `sharp` 作为 Node.js 图片处理库，或使用 Python 的 Pillow。
2. 支持读取文件夹里的常见图片格式。
3. 输出到独立目录，避免覆盖原图。
4. 增加处理日志，记录成功、失败和跳过数量。
5. 加一个配置文件，沉淀常用尺寸和格式。

## 验证方式

```bash
node cli.js --input images --output dist-images --width 1200 --format webp
```

检查输出图片能否打开，宽度是否正确，原图是否未被覆盖。

## 常见坑

- 直接覆盖原图会造成不可逆损失。
- 批量处理大图可能导致内存升高。
- PNG 转 JPEG 会丢透明通道，要提前提示。

## 可复用资产

- 批量文件扫描。
- 进度日志。
- 安全输出目录。
- 图片素材库的处理流水线。

## 产品化判断

单纯图片压缩竞争很激烈。更好的切入点是垂直场景：小红书封面批处理、课程资料图批处理、电商图尺寸统一、知识付费海报素材整理。越贴近具体交付，越可能收费。
