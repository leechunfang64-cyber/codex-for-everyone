# 开发 PPT 生成工具

## 适用场景

PPT 生成工具适合把结构化内容快速变成演示稿初稿，比如课程大纲、销售方案、会议复盘、项目汇报。第一版不要追求高级设计，先解决结构和导出。

## 需求拆解

- 输入：Markdown、JSON 或表单。
- 输出：`.pptx` 文件。
- 必须支持：标题页、目录页、内容页、总结页。
- 暂不支持：复杂动画、高级母版、多人在线编辑。

## Codex 提示词

```text
请开发一个根据 Markdown 生成 PPTX 的命令行工具。
输入 Markdown 使用一级标题作为章节，二级标题作为页面标题，列表作为页面要点。
输出 pptx 文件。
请使用成熟 PPTX 库，提供示例 Markdown 和验证命令。
```

## 实现步骤

1. 解析 Markdown 结构。
2. 映射为 PPT 页面模型。
3. 使用 `pptxgenjs` 或同类库生成文件。
4. 建立基础主题：字体、字号、留白、颜色。
5. 输出示例文件。

## 验证方式

```bash
node cli.js examples/deck.md output/deck.pptx
```

打开文件，检查页面数量、标题、要点和中文字体显示。

## 常见坑

- 一页内容过多会溢出。
- 中文字体在不同系统上表现不同。
- Markdown 结构不规范时需要给出错误提示。

## 可复用资产

- Markdown 到页面模型的转换器。
- PPT 主题配置。
- 内容溢出检查。
- 演示稿生成提示词。

## 产品化判断

泛用 PPT 生成很卷。更有价值的是垂直模板：课程讲义、招商方案、读书分享、项目复盘、私域训练营课件。越贴近某个交付场景，越有复购可能。
