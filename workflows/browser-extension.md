# 开发浏览器扩展

## 适用场景

浏览器扩展适合把网页上的重复动作变成按钮：采集信息、清洗页面、复制内容、标记数据、导出表格。

第一版不要做复杂账号体系。先做一个能在指定网站上稳定工作的本地扩展。

## 需求拆解

- 输入：当前网页 DOM。
- 输出：复制到剪贴板、下载 JSON/CSV、或发送到本地服务。
- 权限：只申请必要网站和必要 API。
- 验收：刷新页面后功能仍稳定，权限不过度。

## Codex 提示词

```text
我要做一个 Chrome 浏览器扩展。
目标：在指定网页上提取页面里的标题、链接和正文摘要，点击按钮后下载 CSV。
请使用 Manifest V3，先实现最小可用版本。
注意权限最小化，并提供本地加载扩展的步骤。
```

## 实现步骤

1. 创建 `manifest.json`。
2. 写 content script 读取页面内容。
3. 写 popup 提供按钮。
4. 生成 CSV 并下载。
5. 在 Chrome 扩展页加载未打包扩展验证。

## 验证方式

1. 打开 `chrome://extensions`。
2. 开启开发者模式。
3. 加载扩展目录。
4. 打开目标网页。
5. 点击扩展按钮，确认 CSV 内容。

## 常见坑

- Manifest V2 和 V3 混用会导致扩展加载失败。
- content script 和 popup 的通信经常写错。
- 权限申请过大，会降低用户信任。
- 目标网站 DOM 一变，采集规则可能失效。

## 可复用资产

- Manifest V3 扩展模板。
- DOM 提取函数。
- CSV 下载函数。
- 权限检查清单。

## 产品化判断

扩展产品的价值在于能否嵌进用户每天的浏览动作。只解决一次性采集，付费弱。能持续节省销售、运营、内容团队时间，才有商业空间。
