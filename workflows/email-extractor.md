# 开发邮箱提取工具

## 适用场景

邮箱提取工具适合从网页、文本、CSV、邮件导出文件里提取线索。这个需求容易被滥用，所以要明确合法来源和使用边界。

## 需求拆解

- 输入：文本文件、HTML 文件、CSV 文件或文件夹。
- 输出：去重后的邮箱列表。
- 规则：校验格式、去重、保留来源文件。
- 风险：不要绕过平台权限，不要抓取不该抓的数据。

## Codex 提示词

```text
我要开发一个本地邮箱提取工具。
输入是一个文件夹，里面可能有 txt、html、csv 文件。
输出是 emails.csv，字段包括 email、source_file、count。
请注意去重、大小写归一、错误文件跳过和 README 使用说明。
```

## 实现步骤

1. 遍历输入目录。
2. 读取支持格式。
3. 用稳健正则提取邮箱。
4. 归一化大小写并去重。
5. 记录来源文件和出现次数。
6. 导出 CSV。

## 验证方式

```bash
node cli.js --input samples --output emails.csv
```

检查重复邮箱是否合并，来源文件是否正确，异常文件是否被跳过。

## 常见坑

- 邮箱正则过宽会提取垃圾字符串。
- 只输出邮箱本身会丢失来源，后续无法复盘。
- 不做合规边界，容易变成低质量骚扰工具。

## 可复用资产

- 文件夹扫描。
- CSV 输出。
- 数据去重。
- 来源追踪。

## 产品化判断

邮箱提取本身不是好生意，容易低价和灰色。更健康的方向是“线索整理和客户资料清洗”，服务已经拥有合法数据的团队，帮助他们降低整理成本，而不是制造骚扰。
