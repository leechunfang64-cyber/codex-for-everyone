# 开发 md 转 Word 工具

## 适用场景

你有大量 Markdown 文档，需要交付给客户、老师、团队或公众号编辑，但对方更习惯 Word。这个工具适合先做成命令行版本，再逐步加拖拽界面。

## 需求拆解

- 输入：单个 `.md` 文件或一个 Markdown 文件夹。
- 输出：对应的 `.docx` 文件。
- 必须保留：标题、列表、表格、代码块、引用。
- 暂不支持：复杂分页、精细 Word 样式、多人协同批注。

## Codex 提示词

```text
我要做一个 Markdown 批量转 Word 的最小可用工具。
请先调研当前项目结构，不要直接写代码。
目标：输入一个 Markdown 文件夹，输出同名 docx 文件夹。
要求：保留标题、列表、表格、代码块和引用。
先做命令行版本，提供 README、示例文件和验证命令。
```

## 实现步骤

1. 选技术栈：Node.js 可用 `unified` / `remark` / `docx`，Python 可用 `pypandoc` 或 `python-docx`。
2. 先支持单文件转换。
3. 再支持文件夹批量转换。
4. 增加错误提示：文件不存在、格式不支持、输出目录不可写。
5. 写 README 和示例。

## 验证方式

```bash
npm run build
node cli.js examples/demo.md output/demo.docx
```

检查输出文件能否被 Word 打开，标题层级和表格是否保留。

## 常见坑

- 只用字符串替换会丢失 Markdown 结构。
- Word 样式不要一开始做太细，否则会陷入低价值调参。
- 批量处理时要跳过隐藏文件和非 Markdown 文件。

## 可复用资产

- Markdown AST 解析模式。
- 文件夹批处理模式。
- CLI 参数模板。
- 文档转换工具的 README 模板。

## 产品化判断

这个工具能不能卖，不取决于转换功能本身，而取决于目标人群是否高频交付 Word。教师、咨询顾问、资料整理者、知识付费团队可能有需求。个人偶尔转换一次，付费意愿通常不强。
